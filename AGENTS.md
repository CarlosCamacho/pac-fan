# Project & Agent Instructions

## Toolchain & Verification
- **Project Type & Stack:** PAK FAN, a maze-chase game in 6809 assembly (LWTOOLS 4.24/4.25 `lwasm`) for the CoCo 1/2 (64K, Semigraphics 12; the SAM runs in all-RAM mode) with CoCo 3 support via `$FF9C`. Python 3 tools (`gen.py`, `tools/`; numpy/Pillow only for the art and audio converters). No Makefile, package.json or composer.json.
- **Build & Test Command:** `LWASM=/path/to/lwasm ./build.sh && tools/checks.sh` (set `XROAR` and `ROMS` first; `build.sh` makes `dist/PAKFAN.DSK`; `checks.sh` should print only PASS lines).
- **Emulator Verification:** For CoCo binaries, test changes in `xroar-dev` (`~/.xroar`) before marking a task complete. Nothing has run on real hardware: say so when reporting.
- **CoCo Hardware Corpus:** For any 6809/6309 assembly, GIME, VDG, SAM, PIA, BASIC, or disk work, read from `$HOME/CoCo-Skills` (pre-installed by the container setup script—do NOT re-clone if that folder exists). Only if `$HOME/CoCo-Skills` is missing, run `gh repo clone CarlosCamacho/CoCo-Skills "$HOME/CoCo-Skills" -- --depth 1` (or construct the standard GitHub HTTPS clone URL for `CarlosCamacho/CoCo-Skills`). Start with `coco-router/SKILL.md` and load only the specific child skill files needed for this task.
- **Project notes:** `CLAUDE.md` is how the engine, the audio engine, the menu and the tests work (read it first); `docs/OWNER-NOTES.md` is the owner's background and history.

## Standing Rules
- **CoCoSDC Required:** Every CoCo program must support CoCoSDC (and DriveWire via DSKCON) and must never hang on a machine without a disk controller, unless explicitly excluded. (PAK FAN does no disk I/O of its own: it is `LOADM`ed.)
- **Hardware Discipline:** Preserve Direct Page (`DP`) state across interrupts/subroutines and strictly respect 8KB MMU bank boundaries. (Here: the audio engine uses DP `$FD`; its entry points run with the game's DP 0 and need `>` extended addressing.)
- **Context Hygiene:** Keep edits focused strictly on the assigned task. Do not refactor or rewrite unrelated files. `tables.inc` and `drawspr.inc` are generated by `gen.py`: never edit them.
- **Project rules:** US English. Never use the Pac-Man name or Namco art/music/sounds. Never white walls. Commit and push finished work to `main`.

  1. Current branch/commit status and what builds cleanly
  2. Immediate next backlog task
  3. Dead ends / failed approaches tried in this session that must not be repeated
- Always include the updated `HANDOFF.md` in your commit/PR.
